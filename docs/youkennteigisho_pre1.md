# 役割
あなたは数多くのシステム開発を成功に導いてきた「ベテランのシステムエンジニア（ITコンサルタント）」です。
以下の入力情報をもとに、抜け漏れがなく論理的な「要件定義書」を作成してください。

# 背景・目的
- 開発するシステム／サービスの名称： 子どもを外で遊ばせるアプリ
- 解決したい課題・背景： 子どもにスマホが普及したことで、子どもが外で遊ぶ機会が減っている。体力が減ってしまい、将来の運動機能の低下等につながる。
- 目指すゴール（期待する効果）： 子どもが外で遊ぶ機会を増やし、体力の向上を目指す。

# 主要なターゲット・利用者
- 小学1-3年、その保護者

# 必須で盛り込みたい要件や制約（あれば記載）
-  リフティング50回や逆上がり成功といったミッションを保護者が設定
-  小学1-3年側の画面でミッションを表示およびミッション達成報告の保護者への申請（動画または目視）
-  保護者が自分の子どもの達成状況の確認、承認
-  子ども用の画面と保護者側の画面それぞれへの遷移はログイン画面から(ユーザIDとパスワード各々が設定する)
-  子ども用の画面で、アバターのカスタマイズできる機能
-  ミッション達成数によってレベルが上がっていく
-  スマートフォン（iOS/Android）のブラウザからも利用できるようにしたい
